# Game ONN Prime — catálogo de jogos
# ---------------------------------------------------------------
# O catálogo real fica em: assets/js/games-data.js
#
# Esta lista é só um rascunho/anotação. Os jogos que aparecem no site
# são os que estão dentro de assets/js/games-data.js (ou os que você
# cadastra pelo painel do site).
#
# Duas formas de adicionar um jogo:
#
#   1) Pelo site (mais fácil)
#      login -> Gerenciar catálogo -> preencher título, gênero,
#      descrição, LINK DIRETO DO JOGO e LINK DA CAPA -> Salvar
#      -> Exportar games-data.js -> substituir o arquivo no repositório.
#
#   2) Editando assets/js/games-data.js
#      Copie o bloco de exemplo que está comentado no arquivo, apague
#      as "//" e preencha com os seus dados.
#
# Cada jogo precisa de:
#   id            identificador único, sem espaços
#   title         nome exibido na galeria
#   genre         gênero (vira filtro automaticamente)
#   description   frase curta
#   url           LINK DIRETO do jogo (https://...)
#   cover         LINK DA CAPA / imagem do jogo (https://...)
#   featured      true = banner principal
#   openInNewTab  true = abre fora da galeria
#   addedAt       data AAAA-MM-DD
# ---------------------------------------------------------------

# Preencha conforme for cadastrando:
# TÍTULO          | GÊNERO  | LINK DO JOGO                    | LINK DA CAPA
# (vazio por enquanto — só entram os jogos que você adicionar)
